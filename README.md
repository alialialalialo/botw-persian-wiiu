# BOTW Persian translation for Wii U (Cemu)

Persian (Farsi) translation of The Legend of Zelda: Breath of the Wild for Wii U v1.5.0 EU (Cemu 1.26.2f), as a graphic pack.

- Original Persian translation (Switch v1.6): Majid Hoshyar, https://www.radoo.ir/author/majidh1/
- Wii U port, fixes, plain-language rewrite: ali123qp

See `HANDOFF.md` for the full method and current status. Game files are NOT included. Keep BCML off.
